Node.js 版本控制器 NVM（Node Version Manager）是一个强大的工具，允许开发者在同一台机器上安装和管理多个 Node.js 版本。本文将详细介绍 NVM 的安装、配置和使用方法。

<!-- more -->

## NVM 简介

<Badge text="版本控制" type="tip" />
<Badge text="开发工具" type="info" />

NVM 是 Node.js 的版本管理工具，它具有以下优势：

1. 允许在同一台机器上安装多个 Node.js 版本
2. 可以根据项目需求快速切换不同的 Node.js 版本
3. 便于测试应用在不同 Node.js 版本下的兼容性
4. 简化了 Node.js 的升级和降级过程

## NVM 下载

NVM 有两个主要版本：

1. [nvm](https://github.com/nvm-sh/nvm) (适用于 Linux 和 macOS)
2. [nvm-windows](https://github.com/coreybutler/nvm-windows) (适用于 Windows)

对于 Windows 用户，您可以从以下地址下载：

- GitHub 官方发布页：[https://github.com/coreybutler/nvm-windows/releases](https://github.com/coreybutler/nvm-windows/releases)
- 镜像下载（仅提供最新版本）：[https://dl.p6p.net/nvm/](https://dl.p6p.net/nvm/)

## NVM 安装步骤

以 Windows 为例，安装 NVM 的步骤如下：

<LinearProcessFlow>

### 卸载现有 Node.js

如果您之前已经安装了 Node.js，请先卸载它以避免潜在的冲突。

### 下载 NVM 安装程序

从上述链接下载 `nvm-setup.exe`。

### 运行安装程序

![直接运行nvm-setup.exe](/assets/img/node/nvm_1.png =500x)

双击运行 `nvm-setup.exe`。

### 选择安装路径

![选择 nvm 安装路径](/assets/img/node/nvm_2.png =500x)

选择 NVM 的安装路径，建议使用默认路径。

### 选择 Node.js 路径

![选择 nodejs 路径](/assets/img/node/nvm_3.png =500x)

选择 Node.js 的安装路径，这是 NVM 将要管理的 Node.js 版本的存放位置。

### 确认安装

![确认安装即可](/assets/img/node/nvm_4.png =500x)

检查设置并确认安装。

### 完成安装

![安装完确认](/assets/img/node/nvm_5.png =500x)

等待安装完成，然后关闭安装程序。

</LinearProcessFlow>

安装完成后，打开命令提示符（CMD）并输入 `nvm`，如果显示可用命令列表，则表示安装成功。

## NVM 常用命令

以下是一些常用的 NVM 命令：

```bash
# 显示帮助信息
nvm help

# 显示 NVM 版本
nvm --version

# 显示可下载的 Node.js 版本列表
nvm list available

# 显示已安装的 Node.js 版本
nvm list

# 切换到指定的 Node.js 版本
nvm use <version>

# 安装指定版本的 Node.js
nvm install <version>

# 卸载指定版本的 Node.js
nvm uninstall <version>

# 显示当前使用的 Node.js 版本
nvm current

# 设置 Node.js 镜像源
nvm node_mirror [url]

# 设置 npm 镜像源
nvm npm_mirror [url]
